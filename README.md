## About Me

I'm a software engineer with 6+ years building enterprise platforms end to end — architecture, backend, front-end, security, and production delivery. I'm the architect and lead developer of Cen EDI Hub & 3i, a Fortune-10 healthcare distributor's partner-onboarding platform spanning 50+ microservices, and I shipped its first production AI service on Azure AI Foundry with Semantic Kernel. I'm focused on Agentic AI systems and spec-driven development, using tools like GitHub Spec Kit, Claude Code, and Cursor to move engineering teams faster without losing rigor.
